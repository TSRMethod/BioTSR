# Methods

These pages describe the TSR methods that BioTSR 1.0 implements. They are
the reference for the science: the conventions, parameters and definitions stated
here are the ones the standard profiles implement.

| page | covers |
|---|---|
| [CROSS_TSR.md](CROSS_TSR.md) | cross-entity TSR: sides, contact pools, the mixed-side candidate rule, the five cross methods, cutoffs, and how the standard differs from the historical cross programs |
| [SSE_TSR.md](SSE_TSR.md) | SSE-TSR: residue secondary-structure states, β-strand identity, the 18 triangle categories, and how the standard differs from the historical SSE program |
| [ANALYSIS.md](ANALYSIS.md) | when two results may be compared, feature representation, common keys, similarity measures and hierarchical clustering |

None of these pages defines command syntax. For the command that runs each
method, see the [reproducibility note](../REPRODUCIBILITY_NOTE.md). For the
decision records behind the conventions, see
[../architecture/DECISIONS.md](../architecture/DECISIONS.md); for the software
structure, see [../ARCHITECTURE.md](../ARCHITECTURE.md).
